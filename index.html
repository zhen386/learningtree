每行一个知识点，用缩进（空格 / Tab）、Markdown 列表或 # 标题表示层级； 支持 [x] 已完成、[~] 进行中。内容会添加到当前选中节点下。

快捷键（焦点在导图上时）

Tab添加子节点（根节点上：Tab 加到右侧，Shift+Tab 加到左侧）
Enter添加同级节点
F2 / 双击重命名
空格切换状态：未开始 → 进行中 → 已完成
Delete删除节点（可撤销）
↑ ↓ ← →移动选择；朝外 / 朝内也用于展开 / 折叠（左侧分支方向相反）
Alt + ↑ ↓调整节点顺序（同侧内）
Ctrl + Z / Y撤销 / 重做
Ctrl + F搜索（Enter 跳到下一个结果）

父节点的状态和进度由其下所有叶子节点自动汇总。 数据保存在本浏览器的 localStorage 中，换浏览器或清理缓存前请先“导出 JSON”备份。

引用本机文件有两种方式： ① 在链接栏粘贴路径（如 D:\资料\笔记.pdf），显示为 📁。双击 index.html 打开本页时可直接点开； 通过 http 地址打开时浏览器会拦截，点击改为复制路径，粘贴到资源管理器地址栏即可。 ② 点“选择本机文件…”（Chrome / Edge），显示为 📄，之后点击直接打开；重新打开页面后首次点击需确认一次授权。 文件关联只保存在本浏览器中，换浏览器后点击会提示重新选择。
